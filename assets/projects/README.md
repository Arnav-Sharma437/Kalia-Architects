## Image Naming & Guidelines:
- **Names**: Use `1.jpg`, `2.jpg`, `3.jpg`, `4.jpg` (or `.png` / `.webp`).
- **Cover Image**: `1.jpg` is always used as the primary thumbnail/cover in the portfolio grid.
- **Slider Images**: `2.jpg`, `3.jpg`, etc. will appear in the project modal slider.
- **Recommended Ratio**: Landscape format (16:9, 16:10 or 4:3) with min width 1600px for crisp mountain photography.
